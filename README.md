# nonebot-plugin-group-game · 群互动游戏

NoneBot2 微信群互动小游戏合集（OneBot v12），16+ 玩法开箱即用：

签到 · 打劫 · 劫色 · 收小弟/打工 · 求婚 · 商店道具 · 贵族 · 银行 · 转账 · 刮刮乐 · 成语接龙 · 财富排行榜

## 💿 安装

```bash
nb plugin install nonebot-plugin-group-game
# 或
pip install nonebot-plugin-group-game
```

在 `bot.py` 或 `pyproject.toml` 中加载插件 `nonebot_plugin_group_game`。

## 🎮 指令一览

| 分类 | 指令 |
| --- | --- |
| 基础 | `签到`、`游戏帮助`、`我的金币` |
| 战斗 | `打劫 @某人`、`劫色 @某人`（CD / 每日上限 / 魅力值） |
| 小弟 | `收小弟 @某人`、`同意`、`拒绝`、`放生`、`赎身`、`小弟打工`、`小弟收工` |
| 社交 | `求婚 @某人`、`离婚`、`转账 N @某人` |
| 消费 | `商店`、`购买 <道具>`、`贵族` |
| 金融 | `存款 N`、`取款 N`、`抢银行`（存款日息 10%） |
| 娱乐 | `刮刮乐`、`购买刮刮乐 N`、`成语接龙 [成语]`、`排行榜` |

经济系统全部走 SQLite 台账：转账零和、道具消费进销毁账户、彩票整池销毁——净金币只出不进，不会通胀。

## ⚙️ 配置（环境变量，均可选）

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `GROUP_GAME_DB` | `<运行目录>/data/group_game.db` | SQLite 数据文件路径 |
| `BRIDGE_URL` | `http://127.0.0.1:9527` | 可选：OneBot v12 桥的 `/nicks` 接口，用于显示**群昵称**；不配置时回退显示用户 ID |

## 🔧 设计要点

- **无 cron**：所有结算在指令入口惰性执行；唯一后台任务是 30 秒巡检（刮刮乐整池销毁 + 成语接龙超时），进程重启后自动补跑
- 仅依赖 `nonebot2`，数据层为标准库 `sqlite3`，单文件即备份
- 群昵称显示走可选 HTTP 桥（`BRIDGE_URL`），任何实现该接口的服务都兼容
